# Locker Scores

This is a Progressive Web App for scoring Locker (7♥) card game. It supports 2–6 players, tracks points and stars, offline use, undo, round history, and follows the rule set you provided.

How to run locally:

1. npm install
2. npm run dev

Build:

npm run build

This scaffold uses React + Vite + TypeScript + Tailwind.
